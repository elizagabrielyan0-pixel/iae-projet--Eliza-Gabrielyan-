S2 · generating-bpmn-files

réutilisable sur d'autres projets

  • Annotations : « Supposé », « À préciser — voir Qx »
  • Mise en page gauche → droite, sans chevauchement
  • Programme Python qui écrit puis vérifie le fichier
  • Anomalie → listée, jamais corrigée en silence
  • Secours : XML dans un bloc de code à copier
