Points à dire : - Le workflow est « step-driven » : je sais comment le travail se fait, donc les étapes sont fixes. - Étape 1 : l'IA lit mes conventions (C4) et deux modèles BPMN de référence (C5 bibliothèque, C6 commande). C'est une étape que j'ai ajoutée : avant, ces règles étaient seulement dans ma tête. - Étape 2 : elle regroupe toutes les sources en gardant l'origine de chaque information. - Étape 3 : elle fait le tableau du processus, une ligne par élément BPMN, avec source et statut. - Étape 4 : elle cherche tout ce qui manque ou se contredit et le transforme en questions pour le client. - Étape 5 : un seul document à relire. Étape 6 : le fichier .bpmn. - Actions externes : aucune. Le workflow est en lecture seule, il ne fait que produire des fichiers. - Avant et après, c'est moi : anonymiser, vérifier le contrat, puis relire et finaliser.
