# Fiche procédure PR-RH-07 — Inscription aux formations internes

**Groupe Verdane — Direction des ressources humaines — version 3**

1. Le salarié saisit sa demande de formation sur l'intranet.
2. Le manager approuve ou refuse la demande sous 5 jours ouvrés.
3. Le service RH vérifie les places disponibles dans la session.
4. Le service RH inscrit le salarié et envoie la convocation.
5. Le service RH archive la demande dans le dossier du salarié.
